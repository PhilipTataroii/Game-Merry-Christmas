# 🎄 GameMerryChristmas

🎁 A fun New Year game built with **Python + Pygame**.  
Help Santa Claus collect all the gifts before they fall!

---

## ✨ Features
- 🕹️ Simple and fun gameplay  
- 🎁 +1 point for each caught gift  
- ❤️ 3 lives — miss a gift and lose one  
- 🔄 Restart easily after losing by pressing any key  

---

## 🕹️ How to Play
- 🖱️ Click on the falling gifts to catch them  
- 🎁 Earn points for every gift you collect  
- ❤️ Don’t miss too many — you only have 3 lives  
- 🔄 If you lose, press any key to restart  

---
