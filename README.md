## 🎮 Overview

GameMerryChristmas is a festive New Year arcade game developed using **Python and Pygame**.

Help Santa Claus collect falling Christmas gifts before they reach the ground! Catch presents, earn points, and try to survive as long as possible.

This project demonstrates practical Python programming skills, event handling, mouse interaction, collision detection, and basic game logic.

## ✨ Features

- 🎄 Festive Christmas-themed gameplay
- 🖱️ Simple mouse controls
- 🎁 Earn 1 point for each collected gift
- ❤️ Start with 3 lives
- 💔 Lose one life for each missed gift
- 🔄 Restart the game by pressing any key after losing
- 🐍 Developed with Python and Pygame

## 🕹️ How to Play

1. Launch the game.
2. Watch for gifts falling from above.
3. Click on the gifts to catch them.
4. Earn **+1 point** for every successful catch.
5. Avoid missing gifts — you only have **3 lives**.
6. When all lives are lost, press any key to restart.

## 🛠️ Technology Stack

- **Programming Language:** Python 3
- **Game Framework:** Pygame
- **Input Handling:** Mouse and keyboard
- **Game Mechanics:** Scoring, lives, collision detection, restart logic

## 🚀 Installation and Running

### 1. Download the Project

Clone the repository or download the project files to your computer.

### 2. Check Python Installation

```bash
python --version
```

### 3. Install Pygame

```bash
pip install pygame
```

### 4. Run the Game

Open a terminal in the project directory and run the main Python game file:

```bash
python main.py
```

*Replace `main.py` with the actual filename if your game's entry point has a different name.*

## 🎯 Game Rules

| Action | Result |
|---|---|
| Click a falling gift | +1 point |
| Miss a falling gift | −1 life |
| Lose all 3 lives | Game over |
| Press any key after game over | Restart the game |
