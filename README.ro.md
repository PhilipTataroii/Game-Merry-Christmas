## 🎮 Prezentare generală

GameMerryChristmas este un joc arcade festiv de Crăciun și Anul Nou, dezvoltat utilizând **Python și Pygame**.

Ajută-l pe Moș Crăciun să colecteze cadourile care cad înainte ca acestea să ajungă la sol! Prinde cadourile, acumulează puncte și încearcă să rezisti cât mai mult timp.

Proiectul demonstrează competențe practice de programare în Python, gestionarea evenimentelor, interacțiunea cu mouse-ul, detectarea coliziunilor și implementarea logicii de bază a jocurilor.

## ✨ Funcționalități

- 🎄 Atmosferă festivă de Crăciun
- 🖱️ Control simplu cu mouse-ul
- 🎁 +1 punct pentru fiecare cadou prins
- ❤️ 3 vieți la începutul jocului
- 💔 Pierderea unei vieți pentru fiecare cadou ratat
- 🔄 Repornirea jocului prin apăsarea oricărei taste după pierdere
- 🐍 Dezvoltat utilizând Python și Pygame

## 🕹️ Cum se joacă

1. Pornește jocul.
2. Urmărește cadourile care cad de sus.
3. Apasă cu mouse-ul pe cadouri pentru a le prinde.
4. Primești **+1 punct** pentru fiecare cadou colectat.
5. Nu rata prea multe cadouri — ai doar **3 vieți**.
6. După pierderea tuturor vieților, apasă orice tastă pentru a începe din nou.

## 🛠️ Tehnologii utilizate

- **Limbaj de programare:** Python 3
- **Bibliotecă pentru jocuri:** Pygame
- **Control:** Mouse și tastatură
- **Mecanici de joc:** Punctaj, vieți, detectarea coliziunilor, repornirea jocului

## 🚀 Instalare și pornire

### 1. Descărcarea proiectului

Clonează repository-ul sau descarcă fișierele jocului pe calculator.

### 2. Verificarea instalării Python

```bash
python --version
```

### 3. Instalarea Pygame

```bash
pip install pygame
```

### 4. Pornirea jocului

Deschide terminalul în directorul proiectului și execută fișierul Python principal:

```bash
python main.py
```

*Dacă fișierul principal are alt nume, înlocuiește `main.py` cu numele corect.*

## 🎯 Regulile jocului

| Acțiune | Rezultat |
|---|---|
| Apăsarea pe un cadou care cade | +1 punct |
| Ratarea unui cadou | −1 viață |
| Pierderea tuturor celor 3 vieți | Sfârșitul jocului |
| Apăsarea oricărei taste după pierdere | Repornirea jocului |
