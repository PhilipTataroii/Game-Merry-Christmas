## 🎮 О проекте

GameMerryChristmas — праздничная новогодняя аркадная игра, разработанная на **Python с использованием Pygame**.

Помоги Санта-Клаусу собрать падающие подарки, прежде чем они достигнут земли! Лови подарки, зарабатывай очки и постарайся продержаться как можно дольше.

Проект демонстрирует практические навыки программирования на Python, обработки событий, взаимодействия с мышью, определения попаданий и реализации базовой игровой логики.

## ✨ Возможности

- 🎄 Новогодняя атмосфера и праздничный игровой процесс
- 🖱️ Простое управление мышью
- 🎁 +1 очко за каждый пойманный подарок
- ❤️ 3 жизни в начале игры
- 💔 Потеря одной жизни за каждый пропущенный подарок
- 🔄 Перезапуск игры нажатием любой клавиши после проигрыша
- 🐍 Разработка на Python и Pygame

## 🕹️ Как играть

1. Запусти игру.
2. Следи за подарками, падающими сверху.
3. Нажимай мышью на подарки, чтобы поймать их.
4. Получай **+1 очко** за каждый пойманный подарок.
5. Не пропускай слишком много подарков — у тебя всего **3 жизни**.
6. После проигрыша нажми любую клавишу, чтобы начать заново.

## 🛠️ Используемые технологии

- **Язык программирования:** Python 3
- **Игровая библиотека:** Pygame
- **Управление:** Мышь и клавиатура
- **Игровая механика:** Очки, жизни, определение попаданий, перезапуск игры

## 🚀 Установка и запуск

### 1. Скачивание проекта

Клонируй репозиторий или скачай файлы игры на компьютер.

### 2. Проверка Python

```bash
python --version
```

### 3. Установка Pygame

```bash
pip install pygame
```

### 4. Запуск игры

Открой терминал в папке проекта и запусти основной Python-файл:

```bash
python main.py
```

*Если основной файл игры называется иначе, замени `main.py` на его настоящее название.*

## 🎯 Правила игры

| Действие | Результат |
|---|---|
| Нажатие на падающий подарок | +1 очко |
| Пропущенный подарок | −1 жизнь |
| Потеря всех 3 жизней | Конец игры |
| Нажатие любой клавиши после проигрыша | Перезапуск |
